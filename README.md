# Qi (Mia) Zhang Personal Website

Academic-style personal website built with React, TypeScript, Vite, and Tailwind CSS.

## Run Locally

```bash
npm install
npm run dev
```

## Edit Content

Personal information, links, projects, publications, blog previews, skills, and honors live in `src/data`.

Replace `src/assets/profile-placeholder.svg` with a formal headshot when available, then update the import in `src/components/Hero.tsx` if the filename changes.
